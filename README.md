# UrbanGrowth_ML

## Predicting Urban Growth with Geospatial Machine Learning Models

This project uses geospatial data, remote sensing, and machine learning
techniques to analyze historical urban growth and predict potential future
urban expansion.

## Project Objectives

1. Map urban extent from 2015–2022.
2. Identify factors influencing urban growth.
3. Train machine learning models to predict future urban growth.
4. Produce urban growth and suitability maps.
5. Develop project presentation and report.


## Project Workflow

The project will follow these major stages:

1. Data collection
2. Data preprocessing
3. Urban extent mapping
4. Urban expansion analysis
5. Identification of urban growth drivers
6. Feature preparation
7. Machine learning model development
8. Model evaluation
9. Future urban growth prediction
10. Urban suitability mapping
11. Visualization and reporting

## Tools and Technologies
